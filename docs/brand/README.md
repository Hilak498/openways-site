# ספר המותג - Open Ways Group

**זהו מסמך הייחוס לכל החלטת עיצוב באתר.** לפני שינוי צבע, טיפוגרפיה, לוגו או
מרווחים - לבדוק כאן, ולא להמציא ערכים חדשים.

## איפה הדברים יושבים

| מה | איפה | במעקב git? |
|---|---|---|
| ספר המותג המקורי (PDF/InDesign) | `docs/internal/brand/` | לא - `/docs/internal/` ב-gitignore |
| הטוקנים שהאתר משתמש בהם בפועל | `src/app/globals.css` (`:root`) | כן |
| קובצי הלוגו | `public/logo-*.png`, `public/logo-*.svg`, `public/Logo.eps` | כן |

הסיבה לפיצול: הריפו ציבורי. הקובץ המקורי נשאר מחוץ למעקב, והערכים שהקוד
באמת צריך מתועדים כאן.

> **סטטוס:** ספר המותג עצמו טרם נשמר בריפו - ההעלאה נכשלה. הערכים למטה
> נמדדו מהקוד ומקובצי הלוגו הרשמיים, והם נכונים למה שהאתר מציג היום.
> כשהקובץ יישמר, יש להשוות מולו ולעדכן את הטבלאות כאן.

## הלוגו

שלוש גרסאות, ובוחרים לפי הרקע:

| קובץ | טקסט | מיועד ל |
|---|---|---|
| `logo-dark-bg.png` | לבן + זהב | רקע כהה (סרגל עליון, hero, פוטר) |
| `logo-light-bg.png` | נייבי + זהב | רקע בהיר (ניירת, מסמכים מודפסים) |
| `logo-mark-*.png` | הסמל בלבד | אייקונים, placeholder |

בקוד: `<Logo variant="light-text" />` לרקע כהה, `variant="dark-text"` לרקע בהיר.

**צבעים שנמדדו מקובצי הלוגו עצמם:**

- זהב הלוגו: `#c7a96d` - הקשתות והמילה "OPEN"
- נייבי הלוגו: `#0d1f3b` - "WAYS GROUP" בגרסה לרקע בהיר

שימו לב שזהב הלוגו (`#c7a96d`) כהה מ-`gold-300` וכהה מ-`gold-400`. הוא חי
בקובצי התמונה ולא בטוקנים, ולכן הוא לא משתנה עם ה-CSS.

## ניגודיות - הכלל שקובע

כל טקסט וכל אלמנט גרפי חייב לעמוד ב-WCAG AA: **4.5:1** לטקסט רגיל,
**3:1** לטקסט גדול ולאלמנטים גרפיים (כולל הלוגו).

זהב הלוגו `#c7a96d` מול המשטחים הבהירים **נכשל**, ולכן הסרגל העליון עבר
לנייבי:

| רקע | ניגודיות מול `#c7a96d` | |
|---|---|---|
| `sand-50` | 2.15 | ✗ |
| `sand-100` | 2.04 | ✗ |
| `sand-200` | 1.93 | ✗ |
| `sand-300` | 1.75 | ✗ |
| `navy-700` | 6.78 | ✓ |
| `navy-800` | 7.59 | ✓ |
| `navy-900` | 7.82 | ✓ |
| `navy-950` | 8.51 | ✓ |

**המסקנה שנגזרת מכאן:** הלוגו המלא לא יושב על משטח חול. רקע בהיר מקבל את
הגרסה `logo-light-bg.png`, שבה "WAYS GROUP" בנייבי נושא את הקריאוּת.

באותו היגיון: `gold-300` הוא לרקע כהה, `gold-700` לרקע בהיר. אסור להחליף
ביניהם.

## טיפוגרפיה

- כותרות: `var(--font-display)`, עם `font-feature-settings: "kern" 0` ו-
  `letter-spacing: 0.012em` - בלי זה אותיות בעברית נדבקות זו לזו.
- מספרים, מטבע ואחוזים: לעטוף ב-`dir="ltr"` כדי למנוע היפוך דו-כיווני.

## עדכון המסמך הזה

אחרי כל שינוי עיצוב שנוגע למותג - לעדכן כאן. אם משהו כאן סותר את ספר
המותג, ספר המותג גובר: לתקן כאן ולתקן את הטוקנים ב-`globals.css`.
